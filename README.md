# Descripción del proyecto
En este laboratorio elegí la opción B. El TFM consistirá en una pizarra digital para entrenadores (FUTPAD), de manera que puedan mover sus fichas de manera táctil en la tablet (o vía web). 
Para este laboratorio haré la landing del producto.

### Cómo arrancarlo: 
``` 
npm install
npm run dev
```

### Opción de integración de Tailwind:
He elegido hacerlo vía PostCSS para ver una manera menos directa que ya que la otra opción, seguramente, sea la que use el resto de las veces.
De esta forma veo que Vite procesa el CSS con PostCSS usando el plugin `@tailwindcss/postcss` para convertir `@import "tailwindcss"` y las clases que se usen.
